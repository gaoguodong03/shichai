1. 书童四九是一个私有化、多用户隔离的 AI Agent 对话与工具平台，测试员需要先理解它的三块入口：工作空间、资源中心、设置。
2. 当前主调用链是浏览器 Vue SPA -> FastAPI /api -> 会话与 Agent 编排 -> ReAct 循环 -> MCP/Skill/文件/沙箱 -> 用户隔离数据与外部服务。
3. 测试的核心不是只看接口成功，而是验证用户可见路径能点通、状态能保存、错误能诊断、不同用户不会串数据。
4. 当前 UI 点击级 E2E 覆盖 7 个 spec 文件、35 个用例，覆盖登录、路由、工作空间、资源中心、设置和分享导入。
5. 测试员交付结论时，需要同时给出命令结果、失败截图/trace、复现路径、影响面和归属层级。
