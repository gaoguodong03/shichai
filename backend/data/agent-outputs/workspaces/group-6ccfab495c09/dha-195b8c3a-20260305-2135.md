## 3. 离职原因深度分析

综合多方报道与内部消息，林俊旸的离职主要源于**组织架构调整**与**技术管理理念分歧**。

### 3.1 组织架构拆分（核心矛盾）
*   **原模式**：Qwen 团队采用“垂直整合”体系，涵盖预训练、后训练、多模态等全流程，利于快速迭代。
*   **新调整**：通义实验室计划将团队**拆散为水平分工**（如预训练组、后训练组独立），并与实验室其他团队合并。
*   **冲突点**：林俊旸认为预训练、后训练及基础设施（Infra）应紧密结合，拆分不符合其对技术趋势的判断，且导致其管理范围被大幅缩小。

### 3.2 管理权变化与“空降”传闻
*   **新任高管**：传闻阿里引入了前 DeepMind/Gemini 研究员 **周浩**，可能置于现有 Qwen 领导层之上或接管部分核心业务（如后训练）。
*   **话语权**：外界推测这导致原核心团队话语权旁落，引发“被架空”的担忧。

### 3.3 资源与考核错位
*   **算力分配**：有消息称大量算力被用于业务交付而非前沿探索。
*   **考核指标**：部分报道指出，基座模型团队曾面临用 DAU（日活）等 C 端产品指标进行考核的压力，与技术研发导向冲突。
