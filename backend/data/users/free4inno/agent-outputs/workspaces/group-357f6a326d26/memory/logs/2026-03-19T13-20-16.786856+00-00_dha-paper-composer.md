## Chapter 2: Skill Representation

### 2.1 Symbolic Representations

Symbolic skill representations treat skills as explicitly defined, interpretable entities with clear input-output specifications. This approach traces its roots to classical AI planning and robotic skill programming, where skills are encoded as functions, APIs, or domain-specific languages (DSLs).

**Function-Based Skills**. The most straightforward symbolic representation defines skills as parameterized functions with preconditions and postconditions. For instance, in the Toolformer framework (Schick et al., 2023), skills are represented as API calls with explicit signatures such as `search(query: str) -> [results]`. This representation enables precise reasoning about skill applicability through precondition checking and guarantees deterministic postconditions. The WebGPT system (Nakano et al., 2021) similarly encodes web browsing skills as discrete actions with well-defined effects, allowing the agent to reason about which skill to invoke based on the current state and goal.
