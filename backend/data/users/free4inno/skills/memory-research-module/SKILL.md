# 智能体记忆研究模块 Skill

## 模块定位

适用于以下场景：

1. 需要理解「记忆」在智能体/大模型系统中的常见划分方式（短期记忆、长期记忆、会话记忆、用户画像等）
2. 需要设计或评审一个带记忆能力的 Agent / 应用（如个人助手、长期陪伴型 Agent、知识管理助手等）
3. 需要梳理当前业界在记忆系统上的常见技术路径（向量数据库、日志+检索、结构化档案等）
4. 需要有一个调研框架，用于持续跟进“记忆相关能力”的最新研究与实践

> 更细节的知识结构与调研要点，可在 `references/memory-notes.md` 中维护。
