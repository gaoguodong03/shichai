**Qwen-3.5 中的“3.5”是通义千问大模型的**版本号**，代表这是 Qwen 系列的第 3.5 代迭代版本。

### 一、版本号的含义
- **3**：主版本号，代表 Qwen 系列的第三代大模型（前序为 Qwen、Qwen-2、Qwen-3）。
- **.5**：次版本号，代表在 Qwen-3 基础上的**重大升级迭代**，而非小修小补的补丁版本。

### 二、Qwen-3.5 相比 Qwen-3 的核心升级
| 升级维度 | Qwen-3 | Qwen-3.5 |
|:--- |:--- |:--- |
| **模态能力** | 文本与视觉分离（Qwen-3 + Qwen-3-VL） | **原生多模态**，文本与视觉早期融合训练 |
| **注意力机制** | 标准 Transformer 注意力 | **混合注意力架构**（Gated DeltaNet + Full Attention） |
| **Agent 能力** | 基础工具调用 | **原生 Agent 设计**，支持 MCP 协议、UI 操控、多步推理 |
| **语言支持** | 119 种语言 | **201 种语言和方言** |
| **上下文窗口** | 最高 128K tokens | 原生 256K，可扩展至 **1M tokens** |
| **推理效率** | 传统架构 | 速度提升约 **19 倍**，部署成本降低约 **60%** |
