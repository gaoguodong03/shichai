# 智能体记忆研究知识提要

> 用途：为“记忆”相关的设计与调研提供基础框架，包括记忆类型、常见技术方案和调研维度。具体最新进展可在实际使用时通过网络搜索补充。

---

## 一、记忆在智能体中的常见划分（概念骨架）

- **瞬时/短期记忆**
  - 当前对话轮次内的上下文信息
  - 模型天然处理的上下文窗口
- **工作记忆**
  - 为完成当前任务临时存放的中间结果和决策状态
  - 可能跨若干轮对话，但不要求长期保留
- **长期记忆**
  - 与用户相关的长期信息（偏好、历史项目、重要事实）
  - 与任务/领域相关的知识积累（笔记、档案、案例）
- **元记忆 / 记忆索引**
  - 描述“有什么记忆、存在哪里、如何检索”的结构化索引

---

## 二、实现记忆的常见技术路径

- **基于向量检索的记忆**
  - 将对话片段、笔记、文档编码成向量，存入向量数据库
  - 在需要时按“相关性”检索，再送回模型作为额外上下文
- **基于结构化档案的记忆**
  - 将用户资料、配置、关键事件以结构化记录（表格/文档）形式保存
  - 通过精确键值或组合条件检索
- **混合方案**
  - 重要、高价值信息使用结构化存储
  - 大量细节、原始对话和文档使用向量检索管理

---

## 三、记忆系统设计时的关键问题（骨架）

- **记什么？**
  - 用户画像：基本背景、偏好、禁忌
  - 任务历史：做过什么、有什么结论和经验
  - 领域知识：与某个长期项目相关的知识
- **如何过滤与压缩？**
  - 避免无界增长的原始日志
  - 提炼出摘要、结论和关键节点，而不是保存所有细节
- **如何检索？**
  - 按主题/标签/时间/任务维度组织
  - 结合向量检索和结构化筛选
