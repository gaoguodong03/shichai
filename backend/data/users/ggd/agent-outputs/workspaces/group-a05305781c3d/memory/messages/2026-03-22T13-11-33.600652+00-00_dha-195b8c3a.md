## 编程 Agent 的兴起与影响
编程 Agent 是一种基于人工智能的工具，它能够辅助甚至替代传统的编程工作。通过自然语言处理技术，用户只需输入简单的指令或描述，Agent 就可以自动生成符合需求的代码。这一技术的发展为工程师、设计师和产品经理带来了巨大变革。

1. **工程师**：从代码的主要生产者转变为关注代码质量和逻辑评审的角色。
2. **设计师**：通过编程 Agent 快速生成交互原型，减少重复劳动。
3. **产品经理（PM）**：更专注于系统化的思维和需求的精准传达。

## 流程的变化：从实现到评审的转向
传统的产品开发流程中，产品需求文档（PRD）是整个团队的协作桥梁。然而，编程 Agent 的出现让实现阶段不再是团队的主要瓶颈，评审环节的质量成为交付成败的关键。

### PRD 的新角色
尽管实现变得简单，描述产品需求的文字和结构化 Prompt 依旧不可或缺。它们不仅是编程 Agent 的输入，也是团队协作的基石。

### 实现与评审的关系
编程 Agent 能快速完成实现，但评审阶段对代码质量、产品逻辑以及用户体验的要求更高。团队需要调整流程，对评审环节投入更多资源。

随着编程 Agent 的普及，团队角色分工正在发生深刻变化。

### 通才的重要性

### PM 的能力分化
编程 Agent 的加入导致产品经理的能力分化：优秀的 PM 能利用 Agent 提升效率，而缺乏系统思维的 PM 则可能面临更大的挑战。

### 系统思维的价值
