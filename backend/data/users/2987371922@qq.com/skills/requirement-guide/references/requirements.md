# 攀岩馆运行管理系统需求清单

---

## 一、用户管理需求

- **会员管理**：支持会员注册（手机/微信/身份证绑定）、信息编辑（姓名、联系方式、紧急联系人、健康状况）、会员等级划分（普通会员、银卡、金卡、年卡等），可设置等级对应的权益（折扣、免费体验时长、优先预约等），支持会员到期提醒、续费提醒，可导出会员数据报表。

- **散客管理**：支持散客临时登记（快速录入基本信息）、临时消费记录留存，可设置散客单次体验价、套餐价，支持散客消费明细查询。

- **权限管理**：区分管理员、前台、教练、保洁等不同角色，分配对应操作权限（如管理员拥有全部权限，前台仅可操作登记、收费，教练仅可查看自己的课程和学员），支持权限修改、角色新增/删除。

## 二、预约管理需求

- **场地预约**：支持会员/散客在线（小程序/系统后台）、线下（前台）预约攀岩场地（难度道、抱石区、训练区），可选择预约时段（精确到小时），显示场地实时占用状态，预约成功后发送短信/微信提醒，支持预约取消、改签，设置预约违约规则（如多次爽约限制预约）。

- **课程预约**：支持教练课程预约（一对一、一对多、团体课），显示教练档期、课程类型（入门课、进阶课、考级课）、课程时长、收费标准，预约后可查看课程详情、教练信息，支持课程请假、补课登记。

- **预约统计**：可按时段、场地、课程类型统计预约量，查看预约高峰时段，为场地调配、教练排班提供数据支持。

## 三、收费管理需求

- **收费设置**：支持多种收费模式（单次收费、会员充值、套餐消费、课程收费），可灵活设置价格（如节假日加价、会员折扣、团体优惠），支持自定义收费项目（如装备租赁、保险费）。

- **支付功能**：支持线下现金、微信、支付宝支付，线上小程序支付，支付成功后自动生成消费凭证，支持退款操作（设置退款规则），可查看支付流水明细。

- **账单管理**：自动生成每日/每月/每年营收报表，可按消费类型、用户类型统计营收数据，支持账单导出、打印，可查询历史消费记录（用户端/管理端）。

## 四、场地与装备管理需求

- **场地管理**：记录攀岩场地（难度道、抱石区）的规格、难度等级，支持场地状态更新（可用、维护、故障），设置场地维护计划（定期检查、保养），记录维护记录，故障时可发起报修流程。

- **装备管理**：建立装备台账（安全带、头盔、攀岩鞋、镁粉袋等），记录装备采购时间、数量、规格、使用年限，支持装备入库、出库、领用、归还登记，设置装备报废标准，提醒装备定期检查、更换，可查询装备库存状态。

- **安全检查**：支持每日场地安全检查（岩壁、保护点、绳索等）、装备安全检查，记录检查结果（合格、不合格、需整改），设置整改期限和责任人，跟踪整改情况。

## 五、教练管理需求

- **教练信息管理**：录入教练基本信息（姓名、资质证书、擅长领域、教学经验），支持教练信息编辑、删除，可展示教练简介（用户端可查看），区分全职/兼职教练。

- **教练排班**：支持管理员为教练安排排班（上课时间、负责场地），显示教练实时排班状态，可调整排班计划，支持教练请假、调班申请，自动同步至课程预约系统。

- **教学管理**：记录教练课程详情（学员、课时、教学内容），支持教练填写教学反馈，可统计教练上课时长、学员评价，为教练考核提供依据。
