# 河南文化知识模块 Skill

## 模块定位

当需要：

- 介绍河南整体情况（地理、人口、气候、交通枢纽等）
- 介绍郑州（省会城市特征、教育资源、互联网/通信行业情况等）
- 为用户推荐河南的旅游路线、景点和玩法
- 介绍河南代表性历史文化（如中原文化、黄河文化、少林、洛阳、开封等）
- 介绍河南饮食、美食、小吃与本地生活体验

时，可以调用本模块作为知识支持。

> 具体的知识点与内容结构，可在后续根据需要补充到 `references/henan-notes.md` 等文件中。
