# 开源周趋势解读

## 输入

- 优先读取工作区 `github-weekly-snapshot.md`（由周榜情报专家写入）。
- 若用户提供了**上一周或历史周**快照，可对比结构变化（新面孔、持续在榜、排名跃迁）。

## 分析输出（Markdown）

1. **主题聚类**：将 Top 项目按方向分组（如 AI 编程助手、Agent 编排、语音/多模态、开发者工具等），每组 2～4 个代表仓库并注明榜单信息来源为周榜 README。
2. **趋势判断**：本周相对近期（若有对比材料）的**热点迁移**——哪些主题在升温或降温；用简短因果说明（社区事件、产品发布、教程传播等），不确定处标注「推测」。
3. **值得跟进的仓库**：列出 3～5 个适合开发者跟进的条目及理由（学习价值、工程落地、风险点）。
4. 将以上内容写入工作区 `opensource-trend-analysis.md`，供简报专家收敛成对外可读文稿。

## 边界

- 不做口号式站队；不虚构 Star 数字。
- 需要站外背景时，用搜索/抓取工具补充，并在分析中注明来源。
