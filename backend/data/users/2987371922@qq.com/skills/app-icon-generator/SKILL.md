## 目标与范围

本技能负责**所有类型的图片生成**：应用图标、文章封面、文内配图、小红书风格信息图。由你根据任务决定**生成几张图**以及**每张图的描述（description）**，再调用工具产出。

- **图标/Logo**：先澄清需求，再组装高质量提示词，用 run_skill_script 或 volces-icon 生成。
- **封面图**：根据文章主题与风格，给出类型/色板/渲染等维度（见下方「封面与配图」），写一条 description 调用一次工具。
- **文内配图**：按段落或要点决定张数与每张内容，逐张写 description 调用。
- **小红书信息图**：1～10 张风格统一的系列图，每张 description 明确风格与版式。

## 图片生成方式（CLI / 工具使用）

本技能要求使用 **run_skill_script** 调用 `scripts/generate_image.py` 生成图标；脚本在自带环境中执行并内部调用火山引擎 API，**不要使用 call_api 工具**做图片生成。

### run_skill_script（唯一推荐）

- **工具名**：单聊为 `run_skill_script`；群聊为 `run_skill_script_app-icon-generator`。生成图标时只调用此工具，不要调用 list_allowed_directories、read_file 等文件/目录类 MCP 来「检查」配置。
- **命名约定（重要）**：群聊中必须优先输出 `run_skill_script_app-icon-generator`。若误输出 `run_skill_script`，后端会做别名映射到 `run_skill_script_app-icon-generator` 作为兼容，但不建议依赖该兼容行为。
- **调用链调试字段**：若执行异常，请检查回合日志中的 `Tool Attempt Debug`、`Tool Raw Outputs`、`Sandbox Entry Trace` 三段；它们分别表示工具名解析、工具原始返回、是否进入 sandbox。
- **参数**：
  - `script_path`：`"generate_image.py"`
  - `input_json`：JSON 字符串，如 `{"description": "你的图标提示词……", "pic_size": "1024x1024"}`，`pic_size` 可选，默认 `1024x1024`
- 脚本内部使用 **ChatAnywhere 图像 API**（POST `https://api.chatanywhere.com.cn/v1/images/generations`），读取环境变量 **CHATANYWHERE_IMAGE_API_KEY**（在 `backend/.env` 中配置，格式 `Bearer sk-xxx` 或仅 `sk-xxx`），与 call_api 无关。
- 工具返回的 stdout 即为图片 URL 或错误信息；你须在最终回复中用 `![图标](URL)` 或可点击链接呈现给用户。

## 工具返回后必须做的事（重要）

- 工具（ run_skill_script 的 generate_image.py）执行成功后会返回**图片 URL**（该原始返回仅存于「原始输出」，用户点击蓝色 MCP 调用块上的「原始输出」可查看）。
- **你必须在最终回复（最终输出）中把该图片呈现给用户**，否则用户在对话里看不到图标：
  - **优先**用 Markdown 图片语法：`![生成的图标](这里填工具返回的图片URL)`。
  - 或至少提供可点击链接：`[点击查看生成的图标](图片URL)`。
- **禁止**只回复「我将为您生成图标」「图标已生成」等文字而不附带图片 URL 或链接；没有链接或图片，用户就看不到最终效果。
- 若工具返回错误或未返回 URL，则说明原因并建议用户重试或调整描述。

## 需求澄清

若用户没给足信息，优先问以下问题（缺哪个问哪个）：

1. **主体是什么**：云/火箭/猫头鹰/字母/抽象形状？
2. **风格**：先给用户灵感清单（不限制只能选这些），让用户直接选一个或自由描述。
3. **颜色与背景**：主色（1-3 种）+ 背景（纯色/渐变/透明感但仍需“干净”）。
4. **尺寸（pic_size）**：输出分辨率。例如：`1024x1024`（应用图标母版，推荐）、`512x512`（头像/小图标）、`768x768`（头像高清/预览）。未说明时默认 `1024x1024`。

如用户说“就按默认”，按：**极简扁平、圆形内图标、1-3 色、高对比、无文字无水印、留足安全边距，尺寸 1024x1024**。

### 风格灵感清单（给用户选择，不局限于此，任选其一或自定义）

当用户没有主动说风格时，先发这段让用户选：

- **可选风格（10 种灵感）**：
  1) 极简扁平（flat minimal）
  2) 渐变矢量（gradient vector）
  3) 线稿/描边（outline）
  4) 3D 渲染（CG render）
  5) 粘土风（clay）
  6) 玻璃拟态（glassmorphism）
  7) 拟物/质感（skeuomorphic）
  8) 像素风（pixel art）
  9) 赛博霓虹（cyberpunk neon）
  10) 电影写真 / 人像摄影（cinematic / portrait）

并补一句：**“也可以不选，直接描述你想要的风格（例如：水彩、国潮、日系、插画、手绘、乐高风等）。”**

## 提示词模板（直接套用）

- **构图**：居中、留足安全边距（大留白）、单主体 + 少量点缀
- **色彩**：1-3 主色（最多 4 色），高对比但不刺眼；常用柔和渐变背景
- **质感**：轻微柔光/阴影/高光即可，避免复杂纹理与噪点
- **约束**：无文字、无数字、无水印、无边框、背景简洁

### 模板 A：极简扁平（最稳）

将方括号替换为具体内容：

```
应用图标，极简扁平矢量风格：[主体]。居中构图，留足安全边距，轮廓清晰，高对比，颜色不超过 3 种。
背景：[背景描述]（纯色或柔和渐变）。无文字、无数字、无水印、无边框、无复杂纹理，干净现代。
```

### 模板 B：高级 3D（偏拟物）

```
应用图标，现代 3D 拟物风格：[主体]。柔和灯光与阴影，材质细腻但保持干净，居中构图，留足安全边距。
背景：简洁纯色或柔和渐变。无文字、无水印、无多余装饰，整体简洁高级。
```

## 常用「负面约束」写法（放进 description 末尾）

为减少“乱画”和脏细节，建议总是加上：

```
无文字、无数字、无水印、无边框、无复杂背景、无杂乱细节、画面干净、图标可读性强。
```

## 其它场景（封面、配图、小红书）

- **封面图**：description 中可包含类型（hero/conceptual/minimal 等）、色板（warm/elegant/cool 等）、渲染（flat-vector/painterly 等）、情绪（subtle/bold）。比例可用 pic_size 如 1792x1024（横版）、1024x1024（方图）。
- **文内配图**：按文章段落或要点逐张生成，每张 description 写明画面主体与风格，保持风格一致。
- **小红书信息图**：多张统一风格（如 cute/fresh/minimal），description 中写明「小红书风格」「信息图」「第 N 张」及本张内容要点。

以上场景均使用同一工具（run_skill_script 的 generate_image.py 或 volces-icon_generate_app_icon），仅 description 与 pic_size 不同。

## 选择 pic_size 的规则

- **默认**：`1024x1024`（最通用、细节最好，后续可裁切/缩放到各平台图标尺寸）。
- **常用选项（分辨率 × 分辨率 - 用途）**：
  - `512x512`（头像 / 小图标 / 预览）
  - `768x768`（头像高清 / 预览更清晰 / 生成更快）
  - `1024x1024`（应用图标母版 / 最推荐）
  - `1536x1536`（需要更细节的母版；若接口不支持则回退 1024）
