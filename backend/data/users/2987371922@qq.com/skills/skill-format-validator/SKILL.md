# 🎯 技能目标
本技能专注于**形式规范**检查。它不关心文字内容是否通顺，只关心是否符合预设的排版和数据格式标准。

# 📋 检查规则库 (严格执行)

## 1. 日期格式校验
- **规则**: 所有日期必须严格匹配正则 `^\d{4}-\d{2}-\d{2}$` (即 `YYYY-MM-DD`)。
- **动作**: 
  - 发现 `2026/3/11`, `2026年3月11日`, `11-03-2026` 等格式，立即标记为错误。
  - 若用户指令包含 "fix"，自动转换为标准格式。

## 2. 中英文空格校验 (盘古之白)
- **规则**: 中文字符与 ASCII 字符（英文、数字、半角标点）之间**必须**保留一个半角空格。
- **错误示例**: `使用Python`, `版本3.0`, `下载APP`
- **正确示例**: `使用 Python`, `版本 3.0`, `下载 APP`
- **动作**: 检测缺失空格处并标记/修复。

## 3. 标点符号混用校验
- **规则**: 
  - 中文语境下严禁出现英文逗号 `,` 和英文句号 `.` (除非在代码块或URL中)。
  - 英文语境下严禁出现全角逗号 `，` 和全角句号 `。`。
- **动作**: 识别上下文语境，标记混用的标点。

## 4. 数据结构完整性校验
- **规则**: 如果文本中包含 JSON 或 XML 代码块：
  - 验证括号是否闭合 `{}`, `[]`, `<>`。
  - 验证键值对冒号、逗号是否正确。
  - 验证 XML 标签是否成对。
- **动作**: 报告语法错误位置（如：第 X 行缺少闭合括号）。

# 🔄 执行流程
1. **扫描**: 逐行分析输入文本。
2. **分类**: 将发现的问题归类为 [日期错误], [空格缺失], [标点混用], [结构错误]。
3. **输出报告**: 
   - 若无错误，输出 "✅ 格式检查通过"。
   - 若有错误，输出 Markdown 表格：[行号/位置] | [错误类型] | [原始片段] | [修正建议]。
4. **执行修复 (仅当用户要求)**: 
   - 输出修正后的完整文本，并在文末注明修改了多少处。

# ⚠️ 注意事项
- **不要**修改文字内容的含义。
- **不要**检查错别字或语病（这是 `proofreader` 技能的工作）。
- 对于代码块内的内容，跳过空格和标点检查，仅检查代码语法。
