# AI 基础设施与工程实践模块 Skill

## 模块定位

适用于以下场景：

1. 需要设计或评审 AI 训练/推理基础设施（包括在线服务与离线任务）
2. 需要理解和对比分布式训练、参数并行/数据并行等方案的工程取舍
3. 需要设计或优化模型推理服务（如高并发、多模型管理、弹性伸缩）
4. 需要为向量检索、向量数据库等组件做架构和工程层设计
5. 需要从整体上规划 AI 系统的 MLOps / 监控 / 部署流程

> 更细致的知识点与结构化提纲，可在 `references/ai-infra-notes.md` 中维护。
