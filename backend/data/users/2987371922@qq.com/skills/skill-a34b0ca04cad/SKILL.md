# 测试·两次问候

## 适用范围

仅用于「顺序双专家测试」场景；**不要**打开任何外链或调用检索。

## 轮次规则（针对本 skill）

在**当前群聊会话**内，统计「用户发过讨论内容之后、你且仅你在本 skill 下给出的回复次数」：

1. 用户发送`你好`（你的正文**只能是**两个字：`你好`（不要引号、不要标点、不要解释）。
2. 用户发送内容不是`你好`，你的正文**只能是**两个字：`再见`。并结束本技能的使用
