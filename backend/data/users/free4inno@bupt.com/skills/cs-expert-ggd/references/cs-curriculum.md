## 一、计算机网络（参考高校《计算机网络与通信》课程大纲）

- **整体视角**
  - 分层模型：应用层 / 传输层 / 网络层 / 数据链路层 / 物理层
  - 关键指标：带宽、时延、吞吐量、丢包率
  - 分组交换 vs 电路交换，面向连接 vs 无连接
- **应用层**
  - Web：HTTP/HTTPS 协议、请求方法、状态码、持久连接、缓存机制
  - 名称解析：DNS 基本工作过程与记录类型
  - 邮件与其他：SMTP/POP3、简单即时通信协议
- **传输层**
  - UDP：无连接、报文边界、适用的实时/多媒体/简单请求场景
  - TCP：连接建立（三次握手）、释放（四次挥手）
  - 可靠数据传输：确认与重传、序号与窗口
  - 拥塞控制与流量控制：慢开始、拥塞避免等基本思想
- **网络层**
  - IPv4 编址、子网划分、CIDR
  - 路由与转发：静态路由、动态路由的基本目标
  - 关键协议：ICMP、ARP、NAT 的直观理解
- **数据链路层与局域网**
  - 差错检测（如 CRC 的直观含义）
  - 以太网帧结构、MAC 地址
  - 交换机与 VLAN 的工程级理解
- **常见工程应用**
  - 高并发接口的网络瓶颈分析（连接数、带宽、RTT）
  - 连接管理与长连接保持策略（如 HTTP Keep-Alive、连接池）

## 二、操作系统（参考高校《操作系统原理》课程大纲）

- **进程与线程管理**
  - 进程概念、进程状态与状态转换
  - 线程模型、多进程 vs 多线程的优缺点
  - 上下文切换、用户态 / 内核态
- **CPU 调度**
  - 常见调度算法：FCFS、SJF、优先级、时间片轮转、多级反馈队列
  - 调度性能指标：吞吐量、周转时间、响应时间
- **内存管理**
  - 连续分配、分区分配
  - 分页、分段与段页式
  - 虚拟内存、页表、TLB
  - 页面置换算法（LRU / FIFO / Clock 等）的直观对比
- **文件与设备管理**
  - 文件抽象、目录结构、文件访问控制
  - 磁盘调度的基本思想
  - I/O 设备、中断、缓冲技术
- **并发控制与死锁**
  - 互斥与同步、临界区
  - 锁、信号量、条件变量的抽象理解
  - 死锁产生条件及预防 / 避免 / 检测与恢复

## 三、数据库系统（参考典型《数据库系统》课程大纲）

- **数据模型与模式设计**
  - 关系模型、主键/外键、范式（1NF/2NF/3NF）
  - 反范式化及其工程动机
- **关系代数与 SQL**
  - 选择、投影、连接等基本操作的概念
  - DDL / DML / DCL 的划分
- **索引**
  - B+ 树索引的核心思想
  - 聚簇 / 非聚簇索引
  - 索引选择的原则与常见误区
- **事务与并发控制**
  - ACID 四特性
  - 并发控制：锁、MVCC、隔离级别
  - 常见问题：脏读、不可重复读、幻读
- **查询与优化**
  - 执行计划的直观理解
  - 常见 SQL 优化思路（减少全表扫描、利用复合索引等）

## 七、Agent 相关技术栈（MCP / Skill / LangChain）

- **MCP / Skill 视角**
  - 将功能拆成“工具”和“技能”，强调单一职责和可组合性
  - Skill 负责：人设、场景、流程；Tool 负责：具体动作（如搜索、读写、执行）
- **LangChain 视角**
  - Chain / Agent / Tool / Router 基本概念
  - 典型模式：工具增强型 Agent、多工具路由、Retrieval + 生成 等
- **与前述课程的连接**
  - 计算机网络/操作系统 → 影响工具执行的性能与可靠性
  - 数据库 → 用于知识库、状态存储与检索
  - 软件工程 → 决定整个 Agent 系统的架构与可演进性
  - Python → 主要实现语言与 glue code
