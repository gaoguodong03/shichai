# 博客协作会话说明

本会话用于：**根据你提供的一篇文章链接，由专家协作完成「读取 → 重写 → 封面图 + 配图」**。

---

## 一、先配置专家（已完成）

以下专家已在 `backend/config/dha_instances.json` 中配置，无需再改。

| 专家名称           | dha_id         | 职责 |
|--------------------|----------------|------|
| 内容生成专家       | `dha-195b8c3a` | 使用 blog-write 等技能：抓取链接正文（fetch）、搜索补充资料（exa）、重写为博客文章 |
| 博客封面与配图专家 | `dha-blog-cover` | 使用 cover-image、article-illustrator：生成封面图及多张文内配图 |

封面与配图专家已绑定图片生成 MCP（`volces-icon`），需在 `.env` 中配置 `VOLCES_IMAGE_API_KEY` 方可出图。

---

## 二、创建会话

1. 在 DHA 前端进入「群聊」或「协作」入口，点击「新建群聊」。
2. **标题**建议：`博客协作（链接→重写→配图）` 或自拟。
3. **选择成员**时勾选：
   - **内容生成专家**（dha-195b8c3a）
   - **博客封面与配图专家**（dha-blog-cover）
4. 创建后，在讨论框中输入「讨论目标」（见下文），再发送链接即可开始。

也可通过 API 创建：

```bash
curl -X POST http://localhost:8000/api/group-sessions \
  -H "Content-Type: application/json" \
  -d '{
    "title": "博客协作（链接→重写→封面与配图）",
    "dha_ids": ["dha-195b8c3a", "dha-blog-cover"],
    "speak_mode": "auto"
  }'
```

---

## 三、讨论目标示例（发起时粘贴或改写）

把下面这段话作为**第一条消息（讨论目标）**发送，并在其后或下一条消息中**附上文章链接**：

```
请根据我提供的链接完成博客协作：
1. 读取该链接的正文内容
2. 重新编写为博客文章（保留核心观点，可按博客风格润色）
3. 为文章生成封面图
4. 在合适位置生成配图（可能不止一张）

我会在下方/下一条消息中给出链接。请先由「内容生成专家」抓取链接并重写，再由「博客封面与配图专家」生成封面和配图。
```

然后发送链接，例如：

```
https://example.com/article/xxx
```

主持人会按流程指定「内容生成专家」先抓取并重写，再指定「博客封面与配图专家」生成封面与配图；所有产出会写入该群聊对应的工作区目录。

---
