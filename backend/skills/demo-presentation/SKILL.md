# 演示技能（Demo Presentation）

本技能仅用于**产品演示**：展示「系统能根据用户意图自动选中本技能并执行」这一流程。

## 执行规则

1. **不调用任何工具**，不要使用 MCP 或 run_skill_script。
2. 用 1～3 句简短、友好的中文回复，内容需包含：
   - 说明「已选中演示技能」；
   - 一句问候或演示确认，例如：「你好，当前已成功加载并执行了演示技能，说明 Skill 的加载与选用流程运行正常。」
3. 不要编造数据、不要输出过长段落，保持简洁清晰即可。
