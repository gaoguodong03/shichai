# 技能目标
本技能用于对用户提供的文本进行严格的排版和数据格式审计。

# 检查规则库
1. **日期校验**: 正则匹配 `^\d{4}-\d{2}-\d{2}$`。发现其他格式立即标记。
2. **空格校验**: 检测中文字符与 ASCII 字符之间是否缺失空格。
3. **标点校验**: 检测中文句子中是否混入英文逗号 `,` 或句号 `.`。
4. **数据结构**: 如果输入包含 JSON/XML，验证其语法完整性。

# 执行流程
1. **接收输入**: 读取用户提供的文本或文件。
2. **逐行扫描**: 
   - 识别不符合上述规则的片段。
   - 记录错误位置（行号/段落）和错误类型。
3. **生成报告**: 
   - 输出一个 Markdown 表格，列出：[位置] | [错误类型] | [原始内容] | [建议修改]。
4. **自动修复 (可选)**: 
   - 如果用户指令包含 "修复"，直接输出修正后的完整文本。
   - 否则，仅输出报告。
