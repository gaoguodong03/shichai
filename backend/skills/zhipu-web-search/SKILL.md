# 智谱网页搜索 Skill

当用户需要**实时网页搜索**、**查最新信息**或**事实核查**时，使用智谱 Web Search MCP 进行搜索。

---

## 一、何时使用本 Skill

- 用户询问**最新资讯**（如今日新闻、近期热点、刚刚发生的事）
- 需要**事实核查**或查询某个具体信息（如某公司简介、某事件时间线）
- 用户明确要求**搜索网上**、**查一下**、**帮我搜**
- 需要获取**实时/动态知识**（非模型训练数据所能覆盖）

---

## 二、可用工具

本 Skill 依赖 `zhipu-web-search` MCP，工具在系统内命名为：

| 工具名 | 参数 | 说明 |
|--------|------|------|
| `zhipu-web-search_web-search` | `query`：搜索关键词（字符串） | 调用智谱 Web Search API 进行网页搜索 |

智谱搜索集成多引擎（智谱标准/高级版、搜狗、Jina、夸克、Bing 等），返回标题、URL、摘要等，适合 LLM 处理。

---

## 三、使用流程

1. **提取搜索意图**：从用户问题中提炼合适的搜索关键词（中文或英文均可）
2. **调用工具**：使用 `zhipu-web-search_web-search`，传入 `query` 参数
3. **整理结果**：将返回的标题、URL、摘要等整合成清晰回答，必要时附上来源链接

---

## 四、典型场景示例

- **「今天比特币价格多少？」** → query: `比特币价格 今日`
- **「2024 年诺贝尔文学奖得主是谁？」** → query: `2024 诺贝尔文学奖`
- **「搜一下智谱 AI 最新融资消息」** → query: `智谱AI 融资 2024`
- **「帮我查某某公司的官网」** → query: `某某公司 官网`

---

## 五、注意事项

1. **仅做搜索**：本 Skill 只负责搜索，不做复杂多步骤调研；若需系统性研究，请使用 `web-research` Skill
2. **关键词精简**：`query` 宜简洁、具体，避免过长句子
3. **引用来源**：回答中尽量附上来源 URL，便于用户追溯
4. **环境变量**：需在 `backend/.env` 中配置 `ZHIPU_WEB_SEARCH_API_KEY`（智谱 BigModel API Key），MCP 会通过 `BIGMODEL_API_KEY` 使用
