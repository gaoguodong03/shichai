# 资源发布测试场景

这个资源包用于验证书童四九可以把一段文字或一个工作区附件发布到文件管理服务。

## 使用方法

1. 在书童四九的“设置 - 环境变量”中新增 `STATIC_CONTENT_API_KEY`，值为你的文件管理系统用户 API Key。
2. 部署包含工作区 Markdown 直传能力的书童四九后端，再在资源中心导入同目录的 `resource-publisher-test.zip`。
3. 新建“资源发布测试”会话。
4. 输入“发布这段文字：……”；或先上传一个文件，再输入“发布此文件”。对 Markdown 文件，输入“将此 Markdown 渲染为网页发布”会生成可直接阅读的网页正文，系统在服务端直接读取文件，不将全文发送给模型；“发布此文件”会保留原始 `.md` 文件。

发布成功后，资源发布专家会返回分享网页地址 `shareUrl`。

## 限制

- 仅在用户明确提出发布时调用接口。
- 每次只发布一段文字或一个附件。
- 附件及渲染为网页发布的 Markdown 最大为 10 MiB；Markdown 可包含内嵌 Base64 图片。
- 所有内容默认公开访问。
- 资源包只保存 `${env:STATIC_CONTENT_API_KEY}` 引用，不包含真实密钥。
