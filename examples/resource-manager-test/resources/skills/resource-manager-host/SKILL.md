# 资源管理场景主持

| 决策前阶段 | 判定条件 | 本轮动作 | 决策后阶段 |
| --- | --- | --- | --- |
| （无） | 最近一条对话消息来自用户，且用户明确要求创建、上传、查询、搜索、查看详情、公开分享、撤销分享、更新、删除或设置密码 | 调度`资源管理专家`：处理用户当前明确的资源任务；业务信息是否充分、资源对象是否唯一和 Markdown 发布形式是否明确均由专家判断 | 资源管理 |
| （无） | 无法从用户输入判断具体资源操作 | 询问用户：当前希望创建、上传、查询、分享、更新还是删除资源 | （无） |
| end | 最近一条对话消息来自用户，且用户提出新的明确资源操作 | 调度`资源管理专家`：处理用户当前新的资源任务，不复用上一任务的完成结论 | 资源管理 |
| end | 用户没有提出新的明确资源操作 | 询问用户：请说明下一项资源管理需求 | end |
| 资源管理 | 最近一条对话消息来自用户，且用户提出新的明确资源操作，而不是回答此前必要问题 | 调度`资源管理专家`：只处理当前用户新提出的资源任务 | 资源管理 |
| 资源管理 | 最近一条对话消息来自资源管理专家，且该消息正在询问资源对象、Markdown 发布形式或其他完成任务必需的信息 | 询问用户：简要转述资源管理专家上一条消息中的必要问题并等待回答；不得设置目标专家，不得把专家自己的提问视为用户回答 | 等待资源信息 |
| 等待资源信息 | 最近一条对话消息来自用户 | 调度`资源管理专家`：依据用户最新回复继续同一资源任务，并传递本轮真实附件或工作区路径；不判断回答内容是否充分，不自行补问，同时处理最新回复中新增的明确资源操作 | 资源管理 |
| 资源管理 | 最近一条对话消息来自资源管理专家，且该消息用真实工具结果确认用户当前明确资源任务已经真实完成，或已提供实际 Owner 管理详情链接，且不存在其他未处理任务 | 告知用户协作结束：当前明确资源任务已经完成 | end |
| 资源管理 | 最近一条对话消息来自资源管理专家，且该消息报告不可恢复失败，没有形成用户要求的结果 | 告知用户协作结束：简要转述真实失败原因，不声称操作成功 | end |
| 资源管理 | 无法确认任务已完成、失败或仍需哪项必要信息 | 询问用户：请确认希望继续的资源操作或补充目标对象 | 资源管理 |
