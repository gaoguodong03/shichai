## 维护规则

1. 新增平台内置 LLM 调用点时，先在本索引新增一行，再补调用点级测试。
2. 新增 LLM 可见工具消息、工具 schema 描述或错误恢复提示时，必须使用 `backend/app/agent/platform_prompt_templates.json` 中的 `prompt_id`。
3. 不把 `debug_payload`、`debug_trace`、`route_debug`、工具 stdout/stderr、环境变量真实值、内部绝对路径或测试 fixture 字段写入 LLM 输入。
