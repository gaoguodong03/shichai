# UI/UX 设计规范

## 整体布局

### 布局结构（三栏）

```
┌─────────────┬──────────────────┬─────────────────────────────────────────┐
│  最左侧列    │    中间列         │              右侧列                      │
│  图标+名称   │   简要列表/摘要   │           主内容区（默认 Chat）            │
│  (导航)     │   (列表/摘要)     │           (详情、预览、聊天界面)            │
├─────────────┼──────────────────┼─────────────────────────────────────────┤
│  • Chat     │ 当前模块的条目    │  默认显示：Chat（当前对话界面）            │
│  • 文件系统  │ 列表或摘要       │  或当前选中条目的完整内容：                │
│  • Skills   │ (可点击选一条)   │  • Chat → 聊天界面（默认）                │
│  • MCPs     │                  │  • Skill → 技能详情、说明、启用状态等      │
│  • 设置     │                  │  • MCP → Server 详情、工具列表等          │
│             │                  │  • 设置 → 具体设置项                      │
│             │                  │  • 文件系统 → 文件预览/下载等              │
└─────────────┴──────────────────┴─────────────────────────────────────────┘
```

### 布局规则

- **最左侧列**：固定导航，宽度 `w-52`，每项为图标 + 名称；点击切换当前模块
- **中间列**：简要列表/摘要，宽度 `w-64`；展示当前模块下的条目，点击选中在右侧显示详情
- **右侧列**：主内容区，`flex-1` 自适应；**默认显示 Chat**，应用打开时即展示聊天界面

## 最左侧五个入口

| 入口       | 图标 | 名称     | 含义 |
|------------|------|----------|------|
| **Chat**   | 💬   | Chat     | 聊天：右侧显示当前对话（消息列表 + 输入框）；中间列为历史对话或当前对话轮次 |
| **文件系统** | 📂 | 文件系统 | Agent 产出的文件：中间列为文件/目录列表，右侧为文件预览或详情 |
| **Skills** | ⚡  | Skills   | 技能配置：中间列为技能列表，右侧为选中技能的详情 |
| **MCPs**   | 🔌  | MCPs     | MCP Server 配置：中间列为 Server 列表，右侧为选中 Server 的详情与工具 |
| **设置**   | ⚙️  | 设置     | 应用设置：中间列为设置分类，右侧为具体设置项（LLM、系统提示词等） |

**顺序**：Chat → 文件系统 → Skills → MCPs → 设置。Chat 位于首位，作为主入口。

---

## 各模块下三栏对应关系

### 1. Chat（默认）

- **左**：高亮「Chat」
- **中**：两种模式
  - **历史对话**：会话列表（+ 新对话、各会话标题与时间）
  - **当前对话**：本轮 Q&A 轮次摘要（点击可跳转到右侧对应位置）
- **右**：聊天界面（消息列表 + 输入框），支持流式输出

### 2. 文件系统

- **左**：高亮「文件系统」
- **中**：文件/目录列表（新建、导入按钮；上一级；条目列表）
- **右**：选中文件时显示预览或下载；选中目录或未选时显示提示

### 3. Skills

- **左**：高亮「Skills」
- **中**：技能列表（+ 添加 Skill；各技能及启用状态）
- **右**：添加 Skill 的表单，或选中技能的详情/编辑

### 4. MCPs

- **左**：高亮「MCPs」
- **中**：MCP Server 列表（+ 添加 MCP；各 Server 及连接状态、工具数）
- **右**：添加 MCP 的表单，或选中 Server 的详情/编辑

### 5. 设置

- **左**：高亮「设置」
- **中**：设置分类（当前为「应用设置」一项）
- **右**：应用设置页面（LLM 配置、系统提示词等）

## Chat 页面详解

### 主界面

- **顶部**：可选的工具调用状态指示器
- **中间**：消息列表
  - 用户消息：靠右显示
  - AI 回复：靠左显示，支持流式输出
  - 工具调用过程：可折叠显示（Thought、Tool Call、Observation）
- **底部**：输入框和发送按钮

### 中间列 Chat 模式

- **历史对话模式**：显示「+ 新对话」及会话列表（标题、时间）
- **当前对话模式**：显示「← 返回历史对话」及本轮 Q&A 轮次摘要；点击某轮可滚动到右侧对应位置

---

## 文件系统

- **含义**：Agent 执行过程中生成或写出的文件（如导出的文章、生成的图标等）在此展示
- **操作**：新建、导入、浏览目录、预览/下载

---

## 界面风格参考

### 参考 ChatGPT/Gemini

1. **对话界面**：消息气泡式布局，用户靠右、AI 靠左，流式输出
2. **输入区域**：底部固定输入框，支持多行，发送按钮或快捷键（Enter/Cmd+Enter）
3. **视觉风格**：简洁现代，清晰层次，合适留白与间距

### 当前实现

- **技术**：Tailwind CSS，无 DaisyUI/Element Plus
- **配色**：`bg-gray-50` 背景，`bg-white` 侧栏，`bg-blue-50` 选中态，`text-blue-700` 高亮

---

## 交互规范

### 滚动行为

- 中间列和右侧列各自独立滚动（`overflow-y: auto`）

### 响应式

- 当前为桌面端布局，移动端可后续扩展（抽屉式导航等）

---

## 工具调用可视化

在 Chat 页面中，工具调用过程建议：

- **展示**：在 AI 回复中可折叠显示 Thought、Tool Call、Observation
- **状态**：调用中显示加载状态，完成后显示结果摘要
- **交互**：默认折叠，用户可展开查看详情
