# 前端布局与导航设计（草案）

本文档描述**三栏布局**和**最左侧导航**的设计意图，供确认理解是否一致后再实现。

---

## 一、整体布局：三栏

```
┌─────────────┬──────────────────┬─────────────────────────────────────────┐
│  最左侧列    │    中间列         │              右侧列                      │
│  图标+名称   │   简要缩写栏      │           详细描述/内容区                │
│  (导航)     │   (列表/摘要)     │           (主内容，默认=Chat)            │
├─────────────┼──────────────────┼─────────────────────────────────────────┤
│             │                  │                                         │
│  • Skill    │  当前选中模块的   │  默认显示：Chat（当前对话界面）           │
│  • MCP      │  条目列表/摘要    │  或当前选中条目的完整内容：               │
│  • Chat     │  (可点击选一条)   │  • Chat → 聊天界面（默认）                │
│  • 对话历史  │                  │  • Skill → 技能详情、说明、启用状态等     │
│  • 设置     │                  │  • MCP → Server 详情、工具列表等        │
│  • 文件系统  │                  │  • 对话历史 → 某条对话的完整内容         │
│             │                  │  • 设置 → 具体设置项                    │
│             │                  │  • 文件系统 → 文件预览/下载等            │
└─────────────┴──────────────────┴─────────────────────────────────────────┘
```

- **最左侧一列**：固定为导航，每一项 = **小图标 + 名称**（**Skill**、**MCP**、**Chat**、**对话历史**、**设置**、**文件系统**）。其中 **Chat** 放在中间位置（Skill / MCP 之后，对话历史 / 设置 / 文件系统之前）。点击某一项，切换当前「模块」。
- **中间一列**：**简要缩写栏**，展示当前模块下的条目列表或摘要（选中 Chat 时中间列可为空或显示「新对话」等；选中其他模块时显示对应列表）。用户在此栏点击某一条，右侧显示该条目的详细内容。
- **右侧一列**：**详细描述区**，**默认显示 Chat（聊天界面）**。应用打开时或选中左侧「Chat」时，右侧展示当前对话（消息列表 + 输入框）；选中其他模块并在中间栏选中条目时，右侧展示该条目的完整内容或主操作区。

---

## 二、最左侧六个入口（图标 + 名称，Chat 在中间位置）

| 入口       | 图标（示意） | 名称     | 含义 |
|------------|--------------|----------|------|
| **Skill**  | 图标         | Skill    | 技能配置：查看/启用/禁用各 Skill，对应中间列「技能列表」、右侧「当前技能详情」。 |
| **MCP**    | 图标         | MCP      | MCP Server 配置：查看/启用/禁用各 Server，对应中间列「Server 列表」、右侧「当前 Server 详情与工具」。 |
| **Chat**   | 图标         | Chat     | **聊天**：右侧**默认**显示聊天界面（当前对话）。选中 Chat 时右侧为消息列表 + 输入框；中间列可为空或「新对话」等。 |
| **对话历史** | 图标       | 对话历史 | 历史会话列表：中间列为会话列表（简要），右侧为选中会话的完整对话内容。 |
| **设置**   | 图标         | 设置     | 应用/模型等设置：中间列为设置分类或条目摘要，右侧为具体设置项表单。 |
| **文件系统** | 图标       | 文件系统 | Agent 产出的文件：中间列为文件/目录列表（简要），右侧为文件预览或详情；**Agent 生成的文件（如图标、导出的文章等）在此展示**。 |

- 最左侧**顺序**：Skill → MCP → **Chat**（中间位置）→ 对话历史 → 设置 → 文件系统。
- 最左侧只做「模块切换」：点击任一项切换当前模块。
- **右侧列默认显示 Chat**：应用首次打开时，右侧列展示聊天界面；选中左侧「Chat」时同样展示聊天界面。
- 中间列、右侧列的内容随「当前选中的模块」以及「在中间列选中的条目」变化。

## 三、各模块下三栏的对应关系（理解确认）

### 0. Chat（默认）

- **左**：当前高亮「Chat」。
- **中**：可为空，或显示「新对话」、快捷入口等（可选）。
- **右**：**聊天界面**（消息列表 + 输入框），为**右侧列默认展示内容**。应用打开时即显示此视图；用户从其他模块切回 Chat 时也显示此视图。

### 1. Skill

- **左**：当前高亮「Skill」。
- **中**：当前已加载的技能列表，每条一行或卡片摘要（如：技能名、启用状态）。
- **右**：在中间栏选中某技能后，显示该技能的详细描述、配置、启用/禁用等。

### 2. MCP

- **左**：当前高亮「MCP」。
- **中**：MCP Server 列表，每条摘要（如：Server 名、连接状态、工具数）。
- **右**：选中某 Server 后，显示该 Server 的详细配置、工具列表、测试等。

### 3. 对话历史

- **左**：当前高亮「对话历史」。
- **中**：会话列表（简要），如：会话标题/首句、时间等。
- **右**：选中某会话后，显示该会话的**完整聊天界面**（消息列表 + 输入框），即当前「聊天」主操作区。

### 4. 设置

- **左**：当前高亮「设置」。
- **中**：设置分类或条目摘要（如：模型、API、界面等）。
- **右**：选中某类后，显示该类下的具体设置表单。

### 5. 文件系统

- **左**：当前高亮「文件系统」。
- **中**：文件/目录列表（简要），包含 **Agent 产出的文件**（如生成的图标、导出的文章、报告等）。
- **右**：选中某文件后，显示预览、下载或详情；若是目录则可在中间列继续展开。

## 四、关于「Agent 产的文件在文件系统中展示」

- **含义**：Agent 在执行过程中生成或写出的文件（例如 app-icon-generator 生成的图标、wechat-article-writer 导出的文章等），应在「文件系统」模块中可见、可管理。
- **实现要点**（后续实现时）：
  - 后端需要约定：Agent 产出文件的存储路径或接口（如统一目录、或通过某 API 列出「Agent 生成文件」）。
  - 前端「文件系统」模块从该来源拉取列表，在中间列展示；右侧做预览/下载等。

## 五、小结（请确认）

1. **三栏**：最左 = 图标+名称（六个固定入口）；中 = 简要缩写/列表；右 = 详细描述/主内容。
2. **最左六个入口（顺序）**：Skill、MCP、**Chat**（中间位置）、对话历史、设置、文件系统。
3. **右侧列默认显示 Chat**：应用打开时右侧列展示聊天界面；选中左侧「Chat」时同样展示聊天界面。
4. **中间列**：随当前模块变化，是「当前模块下的条目列表或摘要」；选中 Chat 时中间列可为空或简单提示。
5. **右侧列**：默认 = Chat（聊天）；随「当前模块 + 在中间列选中的条目」变化时，展示对应详情或主操作区。
6. **文件系统**：专门用来展示和管理 Agent 产出的文件。
