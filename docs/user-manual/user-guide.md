# 用户使用说明

本文面向实际使用者，说明如何从登录进入系统，并完成工作空间对话、资源配置、设置维护和资源包导入导出。

## 1. 登录与账号

打开系统首页后，如果尚未登录，会进入登录页。

- 已有账号：输入账号和密码，点击“登录”。
- 新用户：点击“没有账号？新建账户”，填写账号、密码和确认密码，点击“新建账户”。
- 账号可以使用手机号或电子邮箱格式。

登录成功后进入主界面，左侧主入口包括“工作空间”“资源中心”“设置”和“登出”。

## 2. 工作空间

工作空间用于新建会话、发起群聊、邀请专家和管理会话文件。

### 2.1 新建和进入会话

1. 点击“工作空间”。
2. 点击“新建会话”新建空会话，或在会话列表中点击已有会话。
3. 会话右侧会显示消息记录、成员、输入框和工具栏。

### 2.2 发送消息

1. 在底部输入框填写问题或任务。
2. 需要指定角色时，可以输入 `@` 提及主持人或专家。
3. 点击“发送”。
4. 系统会在消息区显示专家回复；如果任务需要继续确认，按页面提示编辑后点击“确认并继续”。

### 2.3 管理成员

1. 点击输入框工具栏左侧的当前角色按钮。
2. 在“成员管理”弹窗中查看当前成员和可邀请专家。
3. 点击“邀请”把专家加入当前会话。
4. 对非主持人成员，可点击“移出”从当前会话移除。

### 2.4 使用文件

1. 点击输入框工具栏里的“文件”。
2. 可以从工作区选择已有文件插入到消息，也可以从本地上传后插入。
3. 点击右侧“文件”按钮可打开工作区文件面板。
4. 在文件面板中可以新建文件、新建文件夹、上传文件、预览文件和保存编辑内容。

### 2.5 使用场景快捷入口

1. 点击输入框工具栏里的“场景”。
2. 搜索或选择已有场景。
3. 选择后会按场景预设填充会话专家组合和主持人配置。

## 3. 资源中心

资源中心用于维护可复用的场景、专家、技能、工具、模型和文件。

### 3.1 场景

“场景”用于保存一套协作专家和主持人配置。

1. 点击“资源中心 → 场景”。
2. 点击“新建场景”，或从左侧选择已有场景。
3. 填写场景名称和描述。
4. 配置场景主持人的名称、模型、系统提示词和技能。
5. 在“协作专家”中添加需要参与的专家。
6. 点击“保存”。
7. 保存后可导出 ZIP 场景包，供其他账号通过导入功能复用。

### 3.2 专家

“专家”是可被邀请到会话或场景中的角色。

1. 点击“资源中心 → 专家”。
2. 点击“新建专家”，或选择已有专家。
3. 填写专家名称、模型、描述和系统提示词。
4. 选择专家可使用的技能。
5. 点击“保存”。
6. 需要迁移时，可导出专家包，再在目标账号中导入。

### 3.3 技能

“技能”用于描述专家可执行的能力，也可以声明 MCP 工具和 Python 依赖。

1. 点击“资源中心 → 技能”。
2. 点击“新建技能”，或选择已有技能。
3. 编辑技能名称、描述和 `SKILL.md` 正文。
4. 在“技能运行时依赖”中查看 MCP 工具依赖和 Python requirements。
5. 若页面提示沙箱 requirements 缺失依赖，可点击一键添加，或到“设置 → 沙箱”手动维护。
6. 在文件树中维护 `references/`、`assets/`、`scripts/` 等附加文件。
7. 点击“保存”。

技能不一定都需要脚本。写作、资料确认、多人协作、逐阶段打磨这类任务通常应写成“流程型 Skill”，重点说明阶段、确认点、工作区文件规则和什么时候交回主持人；表格处理、爬虫、格式转换、批处理这类确定性任务才写成“脚本型 Skill”，并在 `scripts/` 中提供脚本和参数说明。

#### 3.3.1 技能运行状态

技能运行时，页面可能显示正在处理、等待补充、处理完成或处理失败等状态。

- 如果专家提示缺少文件、链接、参数或确认信息，按提示补充后继续发送。
- 如果专家已经交付最终结果，后续消息会重新交给主持人或当前会话正常调度。
- 如果页面提示脚本、沙箱或工具失败，优先检查该技能声明的工具依赖和“设置 → 沙箱”的 requirements。
- 如果你正在编写或维护 Skill，技术规范见 `docs/skills/skill-standard.md` 与 `docs/skills/skill-session-flow.md`。

### 3.4 工具

“工具”用于配置 MCP Server。

1. 点击“资源中心 → 工具”。
2. 点击“新建工具”，或选择已有工具。
3. 填写工具名称。
4. 选择传输方式：`stdio`、`SSE` 或 `HTTP`。
5. 对远程工具，可选择密钥或使用 `${vault:密钥标识}` 引用密钥。
6. 点击“新建”或“保存”。

### 3.5 模型

“模型”用于配置不同大模型供应商。

1. 点击“资源中心 → 模型”。
2. 选择已有模型，或点击“新建模型”。
3. 填写 Base URL、模型型号和参数。
4. 如需 API Key，优先在“设置 → 密钥”中新建密钥，再在模型配置里选择。
5. 点击“保存”。

### 3.6 文件

“文件”用于跨会话查看工作区文件。

1. 点击“资源中心 → 文件”。
2. 从左侧选择有文件的会话。
3. 在右侧文件树中预览、编辑、新建、上传或删除文件。

## 4. 设置

设置用于维护当前账号的通用偏好和运行环境。

### 4.1 全局

1. 点击“设置 → 全局”。
2. 设置项目整体系统提示词。
3. 设置默认主持人的名称、模型、主持人系统提示词和技能。
4. 点击“保存”。

项目整体系统提示词会进入主持人和专家上下文；默认主持人配置会影响新建普通会话，场景会话可在场景页单独覆写主持人配置。

### 4.2 配色

1. 点击“设置 → 配色”。
2. 选择白色、浅色、暖色、蓝色、黑色、绿色或青色主题。

### 4.3 密钥

1. 点击“设置 → 密钥”。
2. 点击“新建密钥”。
3. 填写密钥标识、显示名称和 API Key。
4. 点击“保存”。

保存后的密钥不会在页面明文展示。模型或工具配置中可引用这些密钥。

### 4.4 账号

1. 点击“设置 → 账号”。
2. 在“修改账号”中填写新账号和当前密码。
3. 在“修改密码”中填写当前密码、新密码和确认密码。
4. 点击对应区域的“保存”。

### 4.5 沙箱

1. 点击“设置 → 沙箱”。
2. 选择沙箱版本：
   - 普通版：资源占用更低，适合普通脚本型技能。
   - Playwright 版：内置浏览器运行时，适合网页自动化技能。
3. 在 requirements 文本框维护当前账号需要的 Python 依赖。
4. 点击“保存沙箱版本”或“保存”。

如果技能页提示依赖缺失，通常需要先到这里补齐 requirements。

## 5. 导出与导入

系统支持通过 ZIP 资源包导入场景、专家、技能或工具。

1. 在资源中心选择对应资源类型，例如“场景”“专家”“技能”或“工具”。
2. 点击导入按钮，选择别人提供的 ZIP 资源包。
3. 页面会显示资源包预览，包括将要导入的对象、依赖和冲突情况。
4. 确认可导入后点击“确认导入”。
5. 导入完成后，到资源中心对应栏目查看导入结果。

导入时按资源名称判断版本：同名资源覆盖本地内容，不同名资源作为新版本导入，系统会自动处理场景、专家、技能和工具之间的内部引用关系。

跨账号迁移时，优先使用 ZIP 资源包。公开分享链接入口已经下线。

## 6. 常见使用建议

- 新会话前先确认“设置 → 全局”和“资源中心 → 模型”已经可用。
- 技能运行失败时，优先检查技能声明的 MCP 工具和“设置 → 沙箱”的 requirements。
- 需要复用一套专家组合时，优先新建“场景”，不要每次手动邀请专家。
- 需要跨账号迁移配置时，优先使用场景、专家、技能或工具的 ZIP 导出和导入。
