## 视觉与主题

- 统一系统配色入口：在 `frontend/src/theme/theme.css` 集中定义 CSS 变量，组件通过 Tailwind / 变量引用，避免颜色散落各处。
- 设计并实现多套页面配色方案（如暖色 / 冷色 / 森林 / 海洋 / 暮色等），并配套深色模式下的同名主题；支持高对比等变体。
- 提供强调色预设（如紫 / 绿等），与浅色、深色模式组合可在设置中切换。
- 专家消息气泡按角色做分色展示（多组克制配色），便于区分不同 Agent。
- 多次迭代主界面与工作区：侧边栏、输入区、会话区、资源列表等布局与动效优化。
- 登录页、着陆页及相关视觉与交互调整。
- Markdown 渲染、图片预览、标签与输入区 UI 等展示层能力完善。

## 会话与群聊编排

- 统一会话模型：以「带主持人的会话」为主，接口收敛到 `/api/sessions/*`（保留历史路径兼容）。
- 群聊流式对话：`POST .../chat/stream`，服务端以 SSE 形态推送增量内容与完整消息，前端解析并更新气泡。
- 编排逻辑迭代：主持人调度、专家发言顺序、自动/手动发言模式、中断与用户补充等（多轮提交持续收紧）。
- 自动模式下策略调整：例如专家本轮未给出「继续执行」类信号时，默认将下一轮建议发言人置为用户等。
- 会话导出、归档、标题与元数据、单条消息删除等工作流。
- 「场景」概念：复用 `session_presets`，在资源中心展示并在群聊中作为协作组合复用；相关 UI 与持久化。
- 协作组合（专家组合）持久化与邀请专家交互（会话内邀请、点击等）。

## 多用户、账号与数据隔离

- 多用户数据目录隔离（每用户独立 `sessions`、`config`、`skills`、`agent-outputs` 等）。
- 登录框架：SQLite 存账号凭证、JWT（或兼容令牌）鉴权；注册/登录与前后端账号格式校验（如手机号、邮箱）。
- 账户与安全相关能力（改密、改名、用户数据目录迁移等，以当前代码为准）。
- 命令行或脚本维护账号（如 `manage_accounts.py` 增删用户及数据）。
- Docker 与依赖、部署相关调整。

## Agent（专家）、Skill 与 MCP

- DHA/专家统一抽象为 Agent：配置入口收敛到 `/api/agents/*`，历史上 `dha-*` 等与 `agent-*` 命名收束。
- 每用户 `dha_instances.json` 配置专家：名称、角色、绑定 Skill、MCP、模型等。
- Skills：用户目录加载 `SKILL.md`、启用/禁用、导入（含 zip）、编辑与脚本目录约定；技能脚本执行与沙箱相关大版本迭代。
- MCP：每用户配置、连接管理、工具列表与调用；侧边栏与资源中心中的 MCP 能力整合；文件类 MCP、Playwright 等扩展。
- 将 Skill 与 MCP、工具网关、工作区文件等串联，支撑网文创作、论文、文件检索等业务向场景。
