# 演示场景说明（明天演示用）

本文档给出**加载和使用 Skill**、**多智能体协同**两个场景的完整演示步骤与可用的 Skill、DHA、会话，直接按步骤操作即可演示。

---

## 演示前准备

1. **启动后端**：在项目根目录或 `backend` 下执行 `uvicorn app.main:app`（或项目既定启动方式）。
2. **启动前端**：在 `frontend` 下执行 `npm run dev`。
3. **登录**：打开前端地址并完成登录（若需要）。
4. **首次请求会触发初始化**：第一次发消息时后端会加载 MCP 与 Skills，若遇超时可再发一次。

---

## 场景一：加载和使用 Skill

**目标**：让观众看到「用户发一条消息 → 系统自动选技能 → 按技能指令执行（可含工具调用）」的流程。

### 操作步骤

1. 进入**工作空间**（左侧导航「工作空间」）。
2. 点击**「+ 新建会话」**，创建新会话（默认会带一个 **Chat** DHA，拥有全部技能，直接与其对话即可）。
3. 在右侧会话界面中：
   - **讨论目标**可填：`演示技能：用数学工具算一道题` 或 `用演示技能打个招呼`。
   - 在输入框发送以下**任选其一**：
     - **「用数学助手算一下 (1+2)^3 等于多少」**  
       → 会选中 `math-assistant`，若配置了 calculator/math-mcp 会调用工具并给出结果。
     - **「请用演示技能执行一下」**  
       → 会选中 `demo-presentation`，直接返回一段演示说明（无需 MCP）。
     - **「用 Script 测试技能跑一下 hello_dha」**  
       → 会选中 `script-demo`，调用 `run_skill_script` 执行 `hello_dha.py` 并返回脚本输出。
4. 发送后观察：
   - 回复中可看到**使用了哪个技能**（若有 skill 标签或 meta）。
   - 若技能需要工具（如数学、脚本），会看到 **ReAct 步骤 / 工具调用**。

### 可选：在资源中心查看 Skill

- 左侧导航进入**资源中心** → **技能**。
- 可展示技能列表（名称、描述、启用状态），以及点击某个技能查看 **SKILL.md** 内容，说明「技能即说明书，系统会先选再执行」。

### 本场景涉及的 Skill（可直接用）

| Skill ID           | 说明                     | 演示话术建议                           |
|--------------------|--------------------------|----------------------------------------|
| `demo-presentation`| 演示用，无工具，易触发   | 「用演示技能打个招呼」/「演示技能」   |
| `math-assistant`   | 数学计算（需 calculator）| 「用数学助手算 (1+2)^3」               |
| `script-demo`      | 执行 scripts 下脚本     | 「用 Script 测试跑 hello_dha」         |
| `default`          | 默认助手，无专用技能时用 | 任意闲聊                               |

## 场景二：多智能体协同

**目标**：让观众看到「多个 DHA 在同一个群聊中按主持人调度轮流发言、协作完成一个目标」。

### 操作步骤

1. 进入**工作空间**。
2. 在左侧会话列表中**选择**以下任一演示用群聊（见下「演示用群聊」）。
3. 在右侧：
   - 在**「群聊讨论目标」**中填入本场要演示的目标，例如：
     - **「一起讨论：明天北京天气如何，如果下雨是否需要带伞」**（天气 + 可扩展其他 DHA）
     - **「教学研讨：我想讨论如何做需求分析」**（教学研讨专用）
   - （可选）**「给下一个 DHA 的提示词」**可留空，由主持人自动分配。
   - 点击发送（或按约定快捷键）。
4. 观察：
   - **主持人**先出现，指定「下面由 XX 发言」。
   - 被指定的 **DHA** 发言（可能带 skill 标签、工具调用）。
   - 该 DHA 发言结束后，主持人再次决定下一发言人，直至「等待用户」或「讨论结束」。

### 演示用群聊（可直接选）

以下会话已存在或已为你准备好，直接在左侧会话列表中点选即可。

| 会话标题           | 用途说明                     | 成员（DHA） |
|--------------------|------------------------------|-------------|
| **多智能体演示**   | 已预建，天气+导航+图标       | 天气感知专家、导航负责人、图片生成负责人 |
| **教学研讨**       | 教师 + 主持人 + 学伴 + 助教   | 研讨教师、学伴研讨主持人、小强、小红、研讨助教 |
| **新对话**（b6ad） | 天气 + 图标                  | 天气感知专家、图片生成负责人 |

### 推荐演示话术（多智能体）

- **多智能体演示**：讨论目标填「规划一次周末出行：先看北京天气，再查从家到景点的路线，最后生成一个出行图标」→ 发送。
- **教学研讨**：讨论目标填「我想讨论：如何做需求分析」→ 发送，观察教师给主题、学伴与助教轮流发言。

### 本场景涉及的 DHA（来自 config/dha_instances.json）

- **天气感知专家**（weather-service）
- **导航负责人**（amap-maps）
- **图片生成负责人**（app-icon-generator）
- **群聊主持人**（group-host，若某群设了 leader）
- **研讨教师 / 学伴研讨主持人 / 小强 / 小红 / 研讨助教**（教学研讨专用）

## 场景三：深度研究（观点/名词 → 核查 → 深入研究 → 报告）

**目标**：用户提出一个观点或一个名词，系统先核查其是否正确，再开展多阶段深入研究，最后整理成一份结构化报告。**不依赖单独主持人**：使用系统默认主持人即可；流程逻辑在「深度研究专家」内完成。

### 操作步骤

1. 进入**工作空间** → **「+ 新建会话」**，创建新群聊。
2. **邀请成员**（1 人或 2 人即可，无需单独主持人 DHA）：
   - **仅 1 人**：只添加 **深度研究专家** → 专家自带「核查→研究→报告」全流程，由系统主持人点名即可。
   - **2 人**：添加 **内容核查专家** + **深度研究专家** → 主持人按通用逻辑点名，核查专家先发言，深度研究专家再基于结论做研究与报告。
3. 在**讨论目标**中填入用户需求，例如：
   - 「我想验证一下“某某说法”对不对，然后对这个主题做深入调研，最后给我一份报告」
   - 「请研究“碳中和”这个概念：先看看常见理解有没有偏差，再深入分析现状和案例，最后整理成报告」
4. 发送后观察：系统主持人点名 → **深度研究专家**（或先**内容核查专家**再**深度研究专家**）按流程完成核查、研究并输出报告。

### 深度研究场景涉及的 DHA 与 Skill

| DHA                 | 角色说明           | Skill / MCP |
|---------------------|--------------------|-------------|
| **深度研究专家**    | 全流程：核查 + 多阶段研究 + 报告；可独立完成或基于已有核查结论直接研究 | deep-research、content-checker；exa、fetch、zhipu-web-search、file-reader |
| **内容核查专家**（可选） | 验证用户观点/名词是否正确，与深度研究专家协作时使用 | content-checker；exa、fetch、file-reader |

详细说明见 **docs/features/deepresearch-scenario.md**。

## 故障排查

- **一直 loading / 超时**：首次请求会初始化 MCP 与 Skills，稍等或再发一次；检查后端日志是否有报错。
- **没有选到预期技能**：技能选择依赖 LLM，可把用户消息写得更明确，例如带「用数学助手」「用演示技能」。
- **群聊不发言 / 一直等用户**：确认该会话已添加至少 1 个 DHA。新建会话默认带 Chat（1 个 DHA），添加其他成员后 Chat 会从会话中移除、已有对话历史保留。
- **数学/脚本/天气等无结果**：检查对应 MCP 或技能是否已启用、后端配置是否正确（如 calculator、amap、volces-icon 等）。

## 总结

| 场景           | 入口               | 关键操作                         |
|----------------|--------------------|----------------------------------|
| 加载和使用 Skill | 工作空间 → 新建会话（0 DHA） | 发一条会触发某技能的消息，观察选技能与执行 |
| 多智能体协同   | 工作空间 → 选已有群聊  | 填讨论目标并发送，观察主持人 + 多 DHA 轮流发言 |

按上述步骤即可完成明天两个场景的演示；如需新增 Skill 或 DHA，见 `backend/skills/` 与 `backend/config/dha_instances.json`。
