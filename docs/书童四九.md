# 书童四九（Shutong Sijiu）架构说明

程序如何跑起来、与专家对话时的整体链路见 [技术架构详解.md](./技术架构详解.md)（框架级说明；接口细节以代码与 backend README 为准）。

## 定位

面向私有化部署的 **多用户隔离** Agent 平台：每个登录用户拥有独立的数据目录、MCP 配置与技能目录；对话与工具调用均在当前用户会话上下文中执行。

## 数据目录

根路径由环境变量 `SHUTONG_USER_DATA_ROOT` 指定（默认 `backend/data/users`）。

每个用户：

- `sessions/`：会话与群聊元数据、历史
- `agent-outputs/workspaces/{workspace_id}/`：工作区文件
- `config/`：`app_settings.json`、`dha_instances.json`、`mcp_servers.json`、`session_presets.json` 等
- `skills/`：用户技能（`SKILL.md` 及脚本）

## 认证

默认 **必须** 携带 `Authorization: Bearer <token>`（由 `/api/auth/login` 或 `/api/auth/register` 签发）。本地调试可设置 `ALLOW_ANONYMOUS_API=1` 以兼容无 token 请求（不安全）。

## Skills 与 MCP

- **Skills**：按用户 `skills_dir` 加载并缓存；变更后由设置接口触发当前用户缓存失效。
- **MCP**：每个用户名对应独立的连接与工具表，配置来自该用户 `config/mcp_servers.json`；修改配置后会释放该用户的运行时并下次懒加载。

## 会话模型

统一会话 API 与群聊共用存储，主入口为 `sessions`。

- 推荐：`/api/sessions/*`
- 兼容：`/api/group-sessions/*`（deprecated）

## 资源中心子菜单

资源中心在左侧导航下提供二级入口（缩进显示）：

- 场景
- 专家
- 技能
- 工具
- 大模型
- 文件

交互规则：

- 点击任一子入口，右侧主区域直接切换到对应资源列表/详情；
- 不再依赖资源中心顶部横向分类标签；
- 群聊输入区的“协作组合”按钮与 chips 继续保留。

## 场景模型（复用 session_presets）

“场景”不引入新存储，直接复用 `session_presets`：

- 接口：`GET/PUT /api/settings/session-presets`
- 字段：`id`、`name`、`dha_ids`、`description`、`discussion_goal_example`
- 用途：
  - 在资源中心中作为场景资源展示；
  - 在群聊中作为协作组合复用。

## 部署提示

- 生产环境设置强随机 `AUTH_SECRET`，关闭 `ALLOW_ANONYMOUS_API`。
- 前端静态资源可由 `STATIC_DIR` 指向构建产物目录，由 `app/main.py` 挂载。
