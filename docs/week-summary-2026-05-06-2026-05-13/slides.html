05 / 11
FROM ONE-OFF FIX TO CONTRACT

沙箱问题被收束到可验证合同

A 之前的故障面
看起来是脚本错

实际经常卡在参数形状、OpenSandbox 配置、宿主路径 allowlist 或镜像架构上。

  • `cli_args_json` 拼接出 Extra data。
  • 容器健康但 `/tmp/sandbox.toml` 不符合预期。
  • arm64 主机拉到不匹配的 sandbox 镜像。
B 本周的稳定面
先验合同 + 实证探针

从入口参数、compose 配置、沙箱创建删除到 Skill 最终态，每层都能被单独验证。

  • `run_skill_script_*` 统一走 CLI 数组 JSON。
  • 真实 sandbox create/delete 取代只看 health。
  • 架构与 host 访问路径有明确 fallback。
